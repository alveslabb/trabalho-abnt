# Trabalho-abnt

📖 Apresentação do Trabalho

Este trabalho tem como finalidade o desenvolvimento de um sistema computacional, aplicando na prática os conceitos teóricos abordados na disciplina de desenvolvimento de sistemas.

O projeto foi elaborado com o objetivo de atender aos requisitos propostos, contemplando funcionalidades essenciais como cadastro de usuários, autenticação e gerenciamento de informações, respeitando critérios de organização, desempenho e segurança.

Durante o desenvolvimento, foram considerados os princípios de engenharia de software, incluindo a definição de requisitos funcionais e não funcionais, bem como a modelagem do sistema por meio de diagramas e estruturas lógicas.

A implementação foi realizada utilizando a linguagem de programação C, com apoio das ferramentas de versionamento oferecidas pelo GitHub, possibilitando o controle de versões e a organização do código-fonte.

Por fim, este trabalho busca consolidar o aprendizado adquirido, demonstrando a capacidade de análise, desenvolvimento e documentação de sistemas computacionais.
